# Product Definition

## Initial Concept
Mermaid Diagram Compiler (v2.0) — это мощная среда разработки для генерации, редактирования и визуализации диаграмм Mermaid с использованием искусственного интеллекта. Проект нацелен на упрощение процесса создания визуальной документации и технических схем.

## Target Audience
- **Разработчики и Системные Архитекторы:** Для быстрой визуализации архитектуры, потоков данных и структур кода.
- **Технические Писатели и Product-менеджеры:** Для создания наглядной документации и схем процессов без глубоких знаний синтаксиса.
- **Студенты и Преподаватели:** Для изучения и обучения методам визуального моделирования.

## Core Value Proposition
- **ИИ-ассистент:** Интеллектуальный помощник для генерации диаграмм из текстовых описаний и авто-исправления ошибок синтаксиса.
- **Интегрированная среда:** Единое пространство для чата с ИИ, редактора кода и предпросмотра результата в реальном времени.
- **Современный стек:** Высокая производительность и отзывчивость благодаря React 19 и Vite.

## Key Features
- **AI Chat & Build:** Разделение общения и генерации диаграмм для точности результата.
- **Markdown Notebooks:** Возможность создавать документы с множеством диаграмм по плану.
- **Live Preview & Editor:** Мгновенное отображение изменений и подсветка синтаксиса.
- **Validation & Auto-fix:** Автоматическое обнаружение и исправление ошибок в коде Mermaid.
- **Local & Cloud LLM:** Поддержка различных провайдеров LLM для гибкости и приватности.
