# Tech Stack

## Frontend
- **TypeScript:** Основной язык программирования.
- **React 19:** UI-библиотека.
- **Vite:** Сборщик и среда разработки.
- **Tailwind CSS:** Фреймворк для стилизации.
- **Lucide Icons:** Библиотека иконок.

## Backend
- **Node.js:** Среда выполнения.
- **Express 5:** Веб-фреймворк для сервера.
- **node-fetch:** Библиотека для выполнения HTTP-запросов.

## Core Libraries & Tools
- **Mermaid:** Ядро для рендеринга диаграмм.
- **PrismJS:** Подсветка синтаксиса в редакторе.
- **ESLint & Prettier:** Инструменты для линтинга и форматирования кода.
- **VitePress:** Для создания документации проекта.

## Architecture
- **Feature-based Structure:** Организация кода по функциональным возможностям.
- **Service Layer:** Выделение бизнес-логики в отдельные сервисы.
- **Strategy Pattern:** Используется для управления различными провайдерами LLM.
