# Product Guidelines

## Visual Identity & UI Style
- **Dark Mode First:** Основной темой является темная (One Dark), обеспечивающая комфортную работу в течение длительного времени.
- **Minimalist & Functional:** Интерфейс должен быть чистым, без лишних декоративных элементов. Основное внимание — на редактор и превью.
- **Modern Standards:** Использование Tailwind CSS для стилизации и Lucide Icons для иконографики.

## User Experience (UX)
- **Immediate Feedback:** Рендеринг диаграмм в реальном времени при изменении кода.
- **Context-Aware AI:** ИИ должен предлагать исправления и улучшения на основе текущего контекста документации Mermaid.
- **Efficient Workflow:** Поддержка горячих клавиш (Enter для чата, Ctrl/Cmd+Enter для сборки) для ускорения работы.
- **Responsive Layout:** Гибкие, настраиваемые размеры колонок чата, редактора и превью.

## Design Principles
- **Clarity over Complexity:** Сложные функции должны быть скрыты за интуитивно понятными интерфейсами.
- **Accessibility:** Использование семантической верстки и доступных цветов.
- **Consistency:** Использование общих UI-примитивов во всем приложении.

## Communication Tone
- **Professional & Helpful:** Ответы ИИ должны быть технически точными, краткими и направленными на решение задачи пользователя.
- **Direct:** Избегать лишних приветствий и многословности в интерфейсе.
