# diagram-compiler (React/Vite)

Это основное SPA-приложение (React + Vite + TypeScript) для генерации/редактирования диаграмм Mermaid.

## Запуск

**Требования:** Node.js

1. Установить зависимости: `npm install`
2. Запустить dev-сервер: `npm run dev`
3. Сборка/превью: `npm run build` / `npm run preview`
4. Проверка типов: `npm run typecheck`

## UX

- **Chat**: отвечает только текстом (уточнения, рекомендации), диаграмму не меняет.
- **Build**: генерирует/обновляет диаграмму из истории чата + текущего кода редактора; запускается даже без нового промпта.
- **MD notebook**: Build создает Markdown с несколькими Mermaid-блоками по planner-плану и строит блоки по очереди.
- **Auto-fix**: после Build при невалидном коде выполняется автофикс (до 5 попыток); кнопка Fix показывает лимит попыток.
- **Preview**: Zoom/Pan, Fit/Reset и полноэкранный режим (fit при входе/выходе).
- **LLM timeouts**: запросы ограничены таймаутом (настраивается в чате) с повтором для текущего шага.
- **Операционные логи**: для Chat/Build/Fix/Analyze отображаются тайминги и контекст (messages/docs) по клику.
- **Проекты**: список сессий; название редактируется inline и сохраняется при потере фокуса.
- **UI-контролы**: единые примитивы и визуально согласованные хедеры/переключатели.
