# AI Strategies Overview

[← Back to Index](./)

В приложении реализовано три независимых пути (стратегии) подключения к LLM.

## Сравнение стратегий

| Фича | OpenRouter (Cloud) | CLIProxyAPI (My Proxy) | Mermaid Agent (Native) |
| :--- | :--- | :--- | :--- |
| **Для кого** | Новички | Профессионалы | Минималисты |
| **Авторизация** | API-ключ | **OAuth (Браузер)** | Системный CLI |
| **Квоты в UI** | Нет | **Да (Графики)** | Нет |
| **Antigravity** | Нет | **Да** | Нет |
| **Приватность** | Средняя | **Высокая** | **Высокая** |

---

## 1. OpenRouter (Cloud)
**Прямое облачное подключение.**
Самый простой способ получить доступ к GPT-4o, Claude 3.5 Sonnet или Gemini 1.5 Pro.

- **Как работает**: Редактор отправляет запросы напрямую к API OpenRouter.
- **Требования**: Только API-ключ.

## 2. CLIProxyAPI (My Proxy)
**Специализированная прокси-интеграция.**
Режим "No-Key Magic". Позволяет использовать ваши существующие подписки через OAuth-сессии консольных инструментов.

- **Как работает**: Редактор подключается к локальному серверу `cliproxyapi`.
- **Подробнее**: [Deep Dive into CLIProxyAPI](ai-cliproxy.md)

## 3. Mermaid Agent (Native Tray)
**Мост к локальным CLI.**
Встроенный компонент Desktop-версии для прямой работы с бинарными файлами.

- **Как работает**: Трей-агент запускает `gemini` или `codex` как подпроцессы.
- **Подробнее**: [Mermaid Agent Guide](ai-agent.md)
