# Basic Workflow: Chat, Build, Fix

[← Back to Index](INDEX.md)

Основной рабочий цикл в Mermaid Diagram Compiler разделен на фазы проектирования и реализации. Это гарантирует точность и минимизирует ошибки.

## 1. Фаза проектирования (Mode: Chat)
Вместо того чтобы сразу писать код, вы обсуждаете диаграмму с ИИ.
- **Действие**: Введите описание задачи (например, "Опиши процесс заказа пиццы") и нажмите **Chat**.
- **Результат**: ИИ создаст **Intent** — структурированное описание сущностей, связей и ограничений. Код на этом этапе не генерируется.
- **Зачем это нужно**: Чтобы вы могли поправить логику до того, как ИИ начнет генерировать сложный синтаксис.

## 2. Фаза реализации (Mode: Build)
Когда Intent вас устраивает, вы переходите к генерации кода.
- **Действие**: Нажмите **Build** (или `Ctrl/Cmd + Enter`).
- **Результат**: ИИ берет Intent, прикладывает к нему документацию Mermaid и генерирует валидный код.
- **Live Preview**: Диаграмма мгновенно отображается в правой колонке.

## 3. Фаза исправления (Mode: Fix)
Если ИИ допустил ошибку в синтаксисе (например, забыл закрыть скобку).
- **Auto-Fix**: Приложение само заметит ошибку и попробует её исправить (до 5 попыток).
- **Manual Fix**: Если автоматика не справилась, вы можете нажать кнопку **Fix** вручную или отредактировать код в центральной колонке.

## 4. Полезные функции редактора
- **Vim Mode**: Для любителей профессиональных редакторов (включается в настройках).
- **Inline Settings**: В шапке превью можно менять Тему (Dark/Light), Стиль (Handdrawn) и Направление (Top-Bottom/Left-Right) без правок кода.
- **Snapshot**: Ручное сохранение версии диаграммы в историю.
