# AI Стратегии и Интеграции

В Mermaid Diagram Compiler реализована гибкая архитектура подключения к LLM. Приложение поддерживает три независимых пути (стратегии), каждый из которых закрывает потребности разных групп пользователей.

## 1. OpenRouter (Cloud)

**Стандартный облачный путь.**
Идеально подходит для быстрого старта и доступа к самым новым моделям без настройки локального окружения.

- **Принцип работы**: прямые HTTP-запросы к API OpenRouter.
- **Требования**: API-ключ OpenRouter (хранится в браузере).
- **Плюсы**:
  - Доступ к большому числу моделей.
  - Не требуется локальная установка CLI.
- **Минусы**:
  - Платный доступ (по токенам).

---

## 2. CLIProxyAPI (My Proxy)

**Путь для профессионалов и энтузиастов.**
Это наиболее функциональный режим, для которого в UI редактора есть специальные визуальные компоненты и мониторинг квот. Он опирается на внешний проект **CLIProxyAPI**.

### Что это такое?
CLIProxyAPI — это локальный прокси-сервер, который превращает ваши авторизованные сессии (OAuth) в стандартный OpenAI-совместимый API.

### Ключевые возможности

1. **Работа без API-ключей (OAuth)**: авторизация в браузере (Google/OpenAI/Anthropic), прокси управляет токенами.
2. **Эксклюзивные провайдеры**: Antigravity, Codex/Claude/Gemini через CLI-сессии, и другие (в зависимости от установки/версии).
3. **Мониторинг квот в UI**: индикаторы квот и лимитов по подпискам (бар-графики).
4. **Балансировка (Load Balancing)**: круговой перебор нескольких аккаунтов (если настроено).

### Как использовать
1. Запустите `cliproxyapi` (по умолчанию `http://localhost:8317`).
2. Выберите провайдер **My Proxy** в редакторе.

---

## 3. Mermaid Agent (Native Tray)

**Нативный путь для Desktop-версии.**
Это лёгкий локальный агент в системном трее, который даёт единый endpoint для UI и запускает установленные CLI-инструменты.

### Поддерживаемые интеграции
- **Gemini CLI** (локальная авторизация пользователя).
- **Codex CLI** (локальная авторизация пользователя).

### Особенности
- **Zero config**: автоматически детектит наличие CLI.
- **Локальный endpoint**: по умолчанию `http://127.0.0.1:8787`.
- **Квоты в UI**: отображение квоты Gemini CLI (через локальную сессию).

## Сравнительная таблица

| Фича | OpenRouter | CLIProxyAPI (My Proxy) | Mermaid Agent |
| :--- | :--- | :--- | :--- |
| **Сложность** | Низкая (только ключ) | Высокая (нужен сервер) | Средняя (нужны CLI) |
| **Цена** | Платно (за токены) | Бесплатно / Подписка | Бесплатно / Подписка |
| **Авторизация** | API Key | OAuth (Browser) | System CLI Auth |
| **Квоты в UI** | Нет | Да | Да (Gemini CLI) |
| **Antigravity** | Нет | Да | Нет |
| **Load Balancing**| Нет | Да | Нет |
| **Тип работы** | Cloud Request | Local Server Proxy | Local Process Spawn |

## Контекст и промпты (кратко)

Промпты собираются динамически в `diagram-compiler/services/llm/prompts.ts`:
- System prompt зависит от режима и типа диаграммы.
- Docs context — выбранные файлы документации (Build Docs).
- Messages — история диалога и текущий код.

В режиме **Build** ответ всегда проходит валидацию через `mermaid.parse()`, при ошибке используется **Auto-Fix**.
