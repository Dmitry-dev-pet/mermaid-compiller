# Обзор проекта

**Mermaid Diagram Compiler** — профессиональная среда для генерации и редактирования диаграмм Mermaid с помощью LLM. Проект объединяет Mermaid.js и современные модели, обеспечивая быстрый цикл «идея → диаграмма → документ».

## Ключевые возможности

### Интеллектуальная генерация
- **Chat/Build Separation**: разделение процесса на проектирование (Intent) и реализацию (Code).
- **Auto-Fix**: автоматическое исправление синтаксических ошибок Mermaid.
- **Markdown Notebooks**: генерация многостраничных документов по плану.

### Приватность и гибкость
- **Local First**: данные хранятся локально (IndexedDB).
- **Mermaid Agent**: локальный мост к CLI-инструментам (`gemini`, `codex`).
- **Cliproxy / My Proxy**: интеграция с локальным прокси для расширенных возможностей и подписок.

### Профессиональный UX
- **Live Preview**: быстрый рендер с Zoom/Pan.
- **Whiteboard**: возможность рисовать поверх диаграмм.
- **Operational Logs**: прозрачность работы ИИ и контекста.
